# 阶段指令与来源

生产流程使用固定版本的 shuohao 阶段指令与模板，由宿主会话派发 Codex 原生子代理生成创作 JSON。上游脚本、参考资料及许可证随项目提供，固定上游版本为 `8af10e0e`。Node.js 18 及以上运行上游 seed、校验、报告和导出脚本。具体阶段、输出和媒体约定见[管线指南](pipeline.md)。

本项目唯一画风为 `cinematic-anime-cg`，资产与分镜图片提示词使用中文，H3 视频提示词使用英文，对白保留原文。

分镜按叙事选择固定、缓推、缓拉或小幅跟随，不要求每镜都运动，避免大幅环绕或显露未知空间。关键交接宜采用固定机位。运镜和景深须写进实际英文 `h3Prompt`，明确焦点及所选景深、背景柔化，并与 `camera`、`lens`、`focus`、`frame`、`shot` 一致。中文 `frame` 固定该切 0 秒的主体、构图、对焦和层次，H3 从此状态继续。`frame` 保留角色名字以绑定参考图，`shot` 和 H3 镜头正文用可见外观描述身份，对白保留原文。拍摄效果不得改变 slot、时间、对白或剧情。

按景别和叙事确定焦平面与清晰目标：

| 画面 | 景深与焦点 |
| --- | --- |
| 人物情绪近景 | 可用浅景深柔化背景，双眼及必要五官清晰。 |
| 双人对话 | 可用中等景深，让两人都清晰。 |
| 环境或建立镜头 | 用较深景深交代空间。 |
| 物件特写 | 选择焦点，保持文字和手物接触清晰。 |

可利用画面中已有的前景柔化、主体清晰与背景渐进柔化形成层次，不凭空添加植物、栏杆等装饰。动态景深只在叙事需要时使用，不得模糊关键动作；优先保持焦点稳定，必要时才明确单次拉焦，不来回抽焦。不堆叠模糊词使主体变糊，也不把运动模糊当成背景虚化。主体与背景距离、焦距和光圈用于表达视觉意图，不保证模型呈现物理效果；可按需要用 35、50、85 mm 或 f/2–f/5.6 描述，不强制数值或极浅景深。默认画幅仍为 9:16，画风仍为 `cinematic-anime-cg`；这些规则用于生成提示词和构图。

同场及整集保持统一电影调色：适度低饱和、自然肤色，按已有光源形成冷暖对比，不逐镜改变 LUT 或画风。优先利用场景已有的侧光、逆光或轮廓光；例如餐厅暖灯与窗外冷夜的对比，不为夜景凭空增加太阳、夕照或灯具。

按叙事选用三分法、已有引导线，以及视线或动作方向的留白，维持轴线和人物空间，不一律将主体放左侧，也不新增前景装饰。可选极细微胶片颗粒，保持眼睛、皮肤、证件和屏幕文字清晰，避免大噪点与强复古褪色，不以颗粒代替材质。所选色光、构图和质感都要落实到 `frame` 和实际 `h3Prompt`，不只记录在元数据中；每镜按叙事取舍，避免堆砌效果，保持关键动作清楚。画幅取生产配置，默认 9:16。
