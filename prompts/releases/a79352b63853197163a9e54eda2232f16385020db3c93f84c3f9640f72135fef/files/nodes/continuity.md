# 任务

为**下一批分镜推理**整理一段有依据的承接摘要。依据上一批最后一个分镜及其视频提示词正文中明确发生的动作，推导脚本所描述的批末人物与场景状态，记录实际存在的角色身份、相对固定空间锚点的位置和朝向、姿态、服装、关键物品持有关系、动作完成阶段、场景及道具状态。不得把计划动作说成已经完成；不得引入下一段剧情的事实。

# 上一批交接状态

{{前批末镜状态}}

# 本批分镜结果

{{本批分镜结果}}

# 裁决

若上一批末镜明确改变状态，以该末镜结束时的描述更新旧摘要。若只能看到图片提示词首帧而没有可确认的末镜动作或结束状态，应明确保留不确定，不把首帧冒充结尾。不得声称看过生成视频、实际帧、用户上传的参考素材或模型执行结果。没有可确认的变化时保留原状态，不为了写摘要补全空白。

同一场景中，仅在已提供且与后续承接相关时，记录光源依托物及其空间位置、时段、镜头观察方向和视点角色；构图或观察方向变化本身不代表人物或光源移动。明确换景或时段改变时，依据新场景已有事实重新确定这些信息，未提供则保持不确定，不凭旧画面补造。摘要只记录文本所描述的状态，不将其视为未见成片的验收结果。

# 输出

只输出合法 JSON 对象，且恰有一个字符串字段 `summary`。简洁但具备可供下批提示词直接注入的状态信息；无法确认的内容明确写“未提供/无法从本批文案确认”。不得输出 Markdown 或其他字段。
