# 任务

为**当前一个分镜**挑选视频全程需要的已有视觉资产，并区分哪些资产已出现在视频第一帧。根据分镜文案及候选卡片，选出确实入画、被使用、被持有，或其场景结构需要持续锁定的准确具体资产。不同衣装或不同状态的卡片是独立候选；按对应画面时间选择准确外观，不把同身份不同外观合并。只要首帧还未显示的资产不得进入 `first_frame_asset_ids`，但如果分镜后续切镜会实际出现或使用，就保留在 `asset_ids`。

# 选择规则

- `asset_id` 必须逐字来自候选卡片；不得改名、编造 ID 或因同身份而替换成外观不匹配的资产。
- `asset_ids` 选择本镜首帧和整段视频任一切镜确实需要的全部候选资产。只在前后文提及、当前镜头未使用的资产不选。
- `first_frame_asset_ids` 仅含当前镜头**第一帧已经可见或正在使用**的资产；后续才入场、稍后才拿起或才被揭示的资产不能进入该数组。该数组每一项必须同时存在于 `asset_ids`。
- 用于第一帧构图的依据必须是该瞬间实际显露的相关外观；持有、使用、知道其存在不等于看得见。盖住或尚未打开的容器内部物件、尚未显露的文字、稍后才出现的造型，只能在它们后续确实需要时进入 `asset_ids`，不能提前进入首帧数组。容器外观与内部物件分别按各自可见时点选择。
- 画外发声、回忆和仅被提及的人物不因此成为可见视觉资产；若本镜始终只闻其声、看不到本人，不为该人选择视觉参考。后续确实入画时才将其加入全程资产，首帧仍按首帧可见范围决定。候选卡片的存在或描述内容不代表参考图片已经生成、可读或通过检查。
- 同一实体的别名只选最匹配的一张具体卡片；若不同造型确实在本镜先后出现，可分别选择相应造型卡片。
- 文案或候选卡片不足以确认时，不猜测。候选中没有可信匹配就不选择该项。
- 按分镜画面中首次需要的顺序返回 ID，并在 JSON 中只输出选中的 ID。

# 输出

只输出合法 JSON 对象：`{"asset_ids":["候选ID"],"first_frame_asset_ids":["首帧候选ID"]}`。两个数组都必须是候选 `asset_id` 的精确子集；`first_frame_asset_ids` 必须是 `asset_ids` 的子集。无匹配项时两个数组均为空。不得输出解释、注释或 Markdown。
