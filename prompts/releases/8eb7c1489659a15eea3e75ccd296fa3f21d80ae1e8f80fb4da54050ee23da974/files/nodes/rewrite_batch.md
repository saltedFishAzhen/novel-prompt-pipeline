任务
将当前章节的每条分镜文案改写得自然、清楚、便于拍摄与后续提示词推理。只处理输入章节中已有的分镜，不能增加、删除、合并或拆分记录。
输入

故事情节（辅助）：
{{故事情节}}
角色信息（辅助）：
{{角色信息}}
场景信息（辅助）：
{{场景信息}}
物品信息（辅助）：
{{物品信息}}
推文文案（辅助）：
{{推文文案}}
章节文案（唯一需要逐条改写的内容）：
{{章节文案}}
改写尺度
以润色和显式化为主：顺句子、补出省略的主语和宾语、把原文可以合理推得的空间关系（谁在哪、面向谁、何时移动）写明白，便于拍摄与后续提示词推理。不得新增画面上可检验的新细节（原文与辅助信息推不出的具体动作、物件、位置、颜色、表情）。原文写“他进屋坐下”时，可写“他走进屋里坐下”，不可写“他推开门走进屋在桌边的椅子上坐下”（门、桌、椅均为新增）。不能确定时保留原有不确定性，不擅自设计细节。辅助信息与章节文案冲突时，以章节文案为准。
规则
辅助信息为空或为“无”时视为未提供，不凭空补足；原文已通顺时可以原样保留。输入标明的分镜编号仅用于 panel_index，不写入 text；编号从0起或不连续均照原值和输入顺序保留，不重新编号。直接对白引号内的笑声用字按原文逐字保留。
每条只改写自己的内容并保持输入编号和顺序。忠实保留角色身份与关系、行动者、情节因果与时间顺序、人物相对位置、服装颜色和穿戴状态、道具归属、地点；不得把其他分镜或概要中的事件加到当前镜。原文直接对白及其语言、标点逐字保留，不得调换说话人或删除关键内容；对白前后的引语（如“他说”“她冷冷道”）可以润色；原文明确将“哈哈”等拟声词用作笑声描写时，按笑声描写处理，不逐字作为台词。不要插入镜头提示词、人物素材标记、其他协议分隔符、工具标签或内部推理；原文确有的字面内容不得随意改造。
输出
只输出合法 JSON 对象，不要代码块或解释：对象仅有 results 数组；每项且仅有 panel_index（与输入完全一致的整数）和 text（对应镜改写的单个字符串）。每个 text 与小说转剧本的单条文案及单条文案改写结果一致，均为一段单行中文自然叙事，表达该镜人物、必要的空间状态、动作及原有对白；不得输出场景、人物、镜头、描述、对话、旁白等字段标签，也不添加景别或运镜指令。text 解码后不得包含实际换行或回车，不用换行分段；不得用 \n 表示段落换行。JSON 字符串中的引号、反斜杠及其他必要字符仍须按 JSON 正确转义；若原文直接对白本身含真实换行或特殊符号，逐字保留与单行冲突时不得自行篡改，须先由外部处理。results 顺序与输入分镜出现顺序一致；若输入编号本身乱序，按输入顺序输出并保留原编号。示例：{"results":[{"panel_index":1,"text":"第一条改写"},{"panel_index":2,"text":"第二条改写"}]}。示例编号与内容不可照搬；输出前自查：每个输入编号恰出现一次，无新增或缺失；输出顺序必须与输入出现顺序完全一致，即使输入编号不是递增顺序，JSON 合法，无裸换行，无尾随逗号。
