任务：从小说提取重要物品并生成英文单视角物品提示词

提取原文中确实出现、具有辨识度或对剧情重要的物品：出现两次及以上、直接参与关键动作、被角色明确持有并随身携带、或被原文单独描写，满足其一即可。同一物品的不同称呼合并，不根据人物职业虚构工具。组成部件、固定附件和容器内附着物随主物件描述，不单独建条；只有原文明示其独立存在或独立参与剧情时才另行提取。
同一物品最多 3 条状态，只保留剧情关键状态。
原文对该物件至少给出 2 项可视觉化事实（形制、部件、材质、颜色、开合或使用状态、可辨尺度各计 1 项）才建条；只有无视觉描写的物件不建条。没有可提取物品时输出 []。

【description 通用要求】
最高优先级：逐条选择且只执行以下一个画面分支。若是断裂变体，且原文不足以确定当前断片的完整轮廓或识别部件归属，使用【断裂局部】；其他记录使用【普通画面】。断裂局部仅描述原文有据的断面、邻近材质和局部取景，不写整体形制、无法确认可见的完整部件或画外部分，不复制基准整体骨架。用 Reuses 子句对应基准。局部裁切是构图选择，不代表画外部件消失；不要把未知情况或裁切理由写进 description。

【命名】
只要某物品存在变体，基准记录的名字一律为「默认的+物品」，不得直接用原文名本身；没有任何变体时，name 就是原文名本身，不加任何前缀。本条命名规则优先于「保留原文写法」的保真规则：「默认的」前缀属于命名规则要求的构造，不算改写原文。
变体一律用「状态说明+物品」的形容词修饰式，状态在前、实体在后、不加括号与标点。状态说明连同连接实体的助词合计最多 8 个汉字；同一实体组内选择能区分各条记录的最少必要状态，单一变化已足以区分时不堆叠其他变化，仍无法区分时才增加必要信息；名称在全数组唯一且读起来自然。
name 在全数组内唯一。

【aliases 口径】
aliases 一律填不带状态说明的原文物品，同一物品组内的基准记录与所有变体都填同一个值。即使原文没有别名，基准记录也要填这一项——它同时是名称来源检查的依据，为空会导致 name 被判为编造。例如 `默认的<物品名>, 状态说明的<物品名>` 两条的 aliases 都是「<物品名>」。aliases 只承担人工对应与来源校验，不承担区分职责，区分只靠 name。原文另有的其他专名照常追加。
必须用英文逗号分隔的字符串；没有其他别名时就填这一个原文名，不要写空字符串、不要写成 [] 或 null。
唯一的例外：变体记录里那句 `Reuses base X: <原文名>` 必须写出原文名，而它正是该组的 aliases。这一句是「description 不得出现 name 或 aliases 字面文字」这条禁令的唯一豁免；除它之外，description 的任何位置都不得出现名称或别名。

【画面与分支】
每条 description 是一张 1:1 正方形白底图片，单一物件、单一视角，不拼版。普通画面选择适合展示主体的单一视角，通常完整显示物件。断裂局部只取断面及相邻表面，物件延伸出画框；不画完整断片、不另画其他部分或承载物。断裂位置、断面形态或材质仅在原文提供时写出，不依据常识补造。两分支互斥：局部取景不同时要求完整主体。

【原文事实】
只写原文支持的物件类别、结构、材质、颜色、纹样、损伤、相对尺度和状态。颜色、痕迹、数量与位置严格绑定原文部位，不将笼统位置细化成具体子部位或前后左右。原文明确与同类比较尺寸时保留比较；无尺度依据时省略。原文明示的环形或中空结构，英文必须明确中心开口或内部中空，而非仅写部件名称。普通画面保留原文明示且当前仍存在的附着、容纳及覆盖关系；附着物外观未详写时仍保留其存在和已知位置，状态明确移除时才省略。断裂局部依照取景分支只保留局部事实。不得根据持用、接触或使用动作推断表面变化，也不补造颜色、部件、材质或功能。可安排取景和光照，但不得改变原文物理属性。

【普通画面骨架】
仅普通画面为同一物件建立 1 至 3 句英文共享骨架：按原文写种类、形制、部件、材质颜色与稳定识别特征，未知项省略。状态变化、开合、断裂、移动与临时附着物不进骨架；原文明示长期存在的旧损可以进入骨架。该物件其他普通画面变体逐字复用同一骨架，包括标点和顺序。断裂局部不执行本节的整体骨架复用要求。

【状态与身份对应】
原文确有重要状态变化才拆变体，基准与变体按公共命名和 aliases 规则对应。变体必须恰好写一次 `Reuses base item: <原文物品名>.`，其后以原文支持的当前画面状态收尾。断裂局部只保留图内可确认的状态，不描述无法确认可见的部件、其他断片或其去向；Reuses 仅用于对应资产，不画成文字。基准记录直接以画面事实收尾，无需独立状态段。

【无人及用字】
画面无人、无手、无人形。英文描述恰好写一次全小写 `no people, no hands, no fingers`，放在句子逗号之后。不写 character、characters，也不用人体部位作尺度参照。right-hand 写 the side on the right，hand pump 写 lever pump，handrail 写 stair rail，nailed 写 pinned；器物 handle 可以使用。

【文字与真实性】
description 为英文、静态可见事实及必要构图，不写资料缺失、推断、遵守约束或裁切原因等解释性元话语；Reuses 子句中的原文物品名是唯一中文例外。只在原文明确要求时呈现画面文字，不添加标签、水印、模型名、参数、对白或夸张质量词。不声称未实际提供的参考图已上传或生成。

【状态段适用范围】
基准记录以图内有据的可见事实结尾，不强制一致性尾句或独立状态段。变体以图内有据的当前状态结尾，不要求描述画外物件或去向。
如有光线描写，变体放在 Reuses 子句之前；Reuses 子句以句号结束，之后只写当前图内有据状态。光线不可单独作为全文末句。

【词数】
基准记录控制在 30 至 180 词 之间，变体记录控制在 30 至 220 词 之间，任何情况下不超过 450 词。原文稀疏时可少于参考词数，不重复表达。词数是参考而非最低要求，断裂局部可约 30 至 80 词；不要为凑词补造事实。普通变体保留骨架和状态，断裂局部只保留已知局部和 Reuses。压缩重复修饰，保留画面有依据的物理事实；任何情况下不超过硬上限。状态段不少于 8 词。

输入材料
小说原文：
{{小说原文}}
推文文案（辅助）：
{{推文文案}}
故事情节（辅助）：
{{故事情节}}
以小说原文为主要依据，辅助材料仅用于消歧，不得凭空增加小说中不存在的实体。

输出格式
只输出合法 JSON 数组。顶层是 []，不是对象，不带 results 包装。不要 Markdown 代码块、前言、注释或总结；整条回复的第一个字符是 [，最后一个字符是 ]。每个对象且仅有 name、aliases、description 三个字符串字段。
description 为英文，可直接用于生图。原文缺失且不能确定的视觉属性直接省略。只陈述可见事实、必要版面要求与规定的 Reuses 对应子句，不写资料是否缺失、写作者是否推断、如何遵守约束或避免添加信息的解释性句子及从句，包括含义相同的改写。原文明确的物理否定事实与版面必需的无人句仍如实保留。所有双引号、反斜杠、换行按 JSON 转义，禁止尾随逗号。没有可提取对象时输出 []，宁可少列不可滥列。

示例结构（禁止照抄内容）：[{"name":"默认的<物品名>","aliases":"<物品名>","description":"English visual description"}]

输出前逐项自查：顶层是数组；name 在全数组唯一；description 为英文、单张图片，画面比例遵守各模式要求；未知属性直接省略，不解释信息缺失、推断过程或遵守约束，保留有据的物理否定与必要版面要求；变体名仅保留组内区分所需状态，实体名前状态说明连同助词不超过 8 个汉字；基准记录与变体记录各自落在自己的词数区间内，都不超过 450 词；变体状态段在最后、基准记录无独立状态段；Reuses 子句至多出现一次且以句号结束；场景和物品遵守各自无人用字规则；角色只用符合其身份的人物或非人指代，三模式均不写 character；不含模型名、参数或对白；单张 1:1 物品画面、一个视角；画面分支只有普通或断裂局部之一；断裂局部只写有据断面与邻近材质，不复制整体骨架、不描述画外部分，以 Reuses 对应基准；普通变体逐字复用有据的共享骨架；每个变体的 Reuses 子句恰好一次并以句号结束；Reuses 子句之后的状态段为完整英文句子且不少于 8 词，只描述当前图内有依据的状态；材质、颜色、位置、数量、损伤和相对尺度均有原文依据，不从动作反推痕迹；普通画面没有遗漏原文明示的当前附着物与容纳关系；环形或中空结构明确写出开口；不解释缺失信息、推断过程或取景原因；不得补造画外状态；包含一次小写 no people, no hands, no fingers；无 character、characters。
