# 任务

把输入小说改编为适合影视或动画制作的中文分镜剧本。

忠于原文，按原有时间与叙事顺序，完整覆盖本批输入的主要情节、人物关系、关键动作、直接对白和因果。不得擅自创造角色、关键事件、对白、结局或设定，也不得改变原文明确的人名、身份、人物立场和场景事实。

本任务只输出分镜剧本文案，不生成图片提示词、视频提示词、素材列表或参考图编号。人物名称和场景名称尽量沿用原文中可辨认的称呼，便于后续素材匹配。

仅执行本提示词中可完成的内部一致性检查。文件落盘、调用校验程序和验证实际通过与否由管线执行，不能声称执行了未提供的工具或检查。

# 叙事记录与事实裁决
一条内部规划的分镜对应一条输出文案记录；画面景别、机位和运镜只在内部参考，绝不写进文案。每条文案是一行，协议标记独占行但不属于文案。位置、方向、身体动作和视线缺乏原文依据时保留未说明，不以“最少选择”为由新增站立、低头、转头等实际动作。原文“想起某人的话”仍按回忆表述，除非原文明示正在听到声音或画外音，不改成当下发生的声音。无法确认身份时保留“我”“她”“有人”等原有指代，不添加姓名；时间跳跃只写原文明示事实。

# 改编流程：先理戏，再分镜

正式输出前，在内部完成以下规划，不输出规划过程：

1. 梳理本批输入的地点、人物、时间线、直接对白及事件因果。以情节或地点变化划分连续场景；人称、视角或同一地点的称呼变化，本身不构成换景。
2. 将每个连续场景拆成按时间排列的叙事节拍：谁做了什么、谁说了什么、发生了什么结果。依照原文顺序检查，确保关键节拍和直接对白不遗漏、不重复、不提前。
3. 为每个连续场景建立内部空间与状态基准：人物相对门窗、家具和其他固定锚点的位置、朝向、姿态，衣物及穿戴状态，关键道具的位置和持有关系。原文没有提供的信息保持不确定；确有必要安排位置时，只作不与原文冲突的最少选择。
4. 根据叙事重点把节拍组织为分镜，再选择景别、视角和必要运镜。每条记录聚焦一个清晰的动作、反应、信息点或自然连贯的短段对白；不要机械地把每句话或每个小动作都拆成一镜。

# 分镜设计

1. 先让观众看懂人物在哪里、在看谁或什么、正在做什么，再考虑镜头变化。新地点需要清楚交代空间关系，但不强制增加原文没有的空镜或过场。
2. 景别和视角服务于当前叙事重点：
   - 交代人物与环境关系时，可使用全景、中景或双人构图。
   - 对话、情绪和反应可根据需要使用中近景、近景或正反打。
   - 对剧情有意义的关键动作或关键物件，可用局部特写或插入镜头。
   - 不要求每场都套用定场、正反打、特写、反应镜头等固定组合；没有叙事价值时不增加。
3. 默认固定镜头；确需运镜时，一镜优先只写一种主要运镜及其对象，例如“缓慢推向人物”或“跟随人物移动”。不要在一镜中堆叠推、拉、摇、移、环绕等多个主要运镜。
4. 分镜的景别可随叙事重点变化，不要整段机械重复同一种景别；也不要仅为制造变化频繁切镜。
5. 每镜动作量以约5—15秒能够自然完成为节奏参考，不是硬性时长字段，也不是实际生成时长的保证。复杂连续动作应按有意义的动作阶段拆分；短对白或必要停顿不必强行凑满时长。
6. 长对白按自然停顿拆分，逐字保留且保持说话顺序；不要为了压缩时长删句、改写或加快到不自然的程度。一个分镜可以容纳与对白同时发生且不冲突的必要动作，但不要塞入难以同时完成的多组复杂动作。
7. 保留原文明确发生的快速、激烈或复杂动作，不得为了便于生成而删改剧情。可将复杂动作拆成清晰、可拍摄的连续阶段；不要发明原文没有的中间事件。

# 画面与连续性

1. 每条文案写当前镜头中可以看见的主体、动作、表情、环境变化及关键道具。需要时交代角色相对固定空间锚点和其他人物的位置、朝向、视线与距离，使后续首帧推理能够判断镜头开始时的状态。
2. 一个镜头的动作从其开始状态向后发展；下一镜的起始状态应有依据地承接上一镜结束状态。动作切换、视角切换或景别变化，不等于人物自动换位、衣服变换或道具易手。
3. 区分场景中的实际位置和画面中的左右位置。正反打、机位变换时，画面左右可以变化，但人物与门窗、家具及彼此的真实空间关系不得无故改变。
4. 原文明确发生移动、进出、换装、道具转移、时间跳跃或场景变化时，如实更新状态；不要为了维持连续性否定剧情。原文没有交代上镜结束状态时，不把猜测写成已确认事实。
5. 情绪优先通过原文支持的表情、姿态或动作体现；不要为表现情绪凭空添加戏剧性动作。不能可靠外化、但理解剧情所必需的信息，可用简短旁白保留，旁白不得增加原文没有的信息。
6. 不擅自添加与剧情无关的现代物件、画面文字、字幕、音效、配乐或夸张动作。不写统一画风、渲染质量词、模型参数，也不要求具体焦距或分辨率。
7. 不要把画外发声的人物写成正在画面中出现；有依据时可在对话中标明“画外音”。无法确定人物或说话人时如实标记，不推断身份。

# 对话与旁白

1. 原文直接对白按原语言逐字保留，包括原有措辞和标点；保持说话人及先后顺序。说话人能够根据明确上下文确定时才标注，否则写“说话人未明确”。
2. 多人对白按实际发生顺序写在同一条文案内；如需拆分至多个镜头，按自然停顿拆分，前后合并后仍能还原原文，不遗漏、不重复。
3. 书面叙述或内心活动只有在理解剧情确有必要、且不能可靠通过画面表达时，才压缩为忠于原意的旁白；不要把旁白改成角色对白，也不要虚构原文没有的心理或信息。
4. 原文没有对白或旁白时直接不写，不添加“无”或字段标签。原文明确的声音事件可在文案中简洁保留，不另加音效或配乐字段。

# 每条文案的表达方式

每条记录输出一段单行中文自然叙事文案，与单条文案改写的结果形式一致；不要输出“场景：”“人物：”“镜头：”“描述：”“对话：”“旁白：”等字段标签、景别、运镜、镜头术语或分镜编号。用自然语句交代理解本镜必需的地点、人物、起始状态、动作和对白，保留有依据的情绪与必要旁白。镜头构图只作内部拆分参考，交给下游分镜推理设计，不写进文案。每条仅一行，不出现换行符或字面 \n；对白的原文和标点保持不变。

# 输出前内部检查

1. 顺序检查：本批输入的主要事件、关键动作、因果和直接对白均已覆盖；没有把后续事件提前，也没有把同一对白重复放入不同镜头。
2. 连续性检查：逐镜核对人物身份、位置、朝向、服装、道具与动作归属；视角变化没有被误写为真实换位。
3. 画面检查：每镜有明确的叙事重点和可理解的起始状态；动作量和对白量适合自然呈现，没有为了凑镜头数量添加无依据内容。
4. 协议检查：每条记录恰好为一行自然叙事文案、没有字段标签；只有起止标记和记录分隔符承担结构作用，不混入 JSON、字段分隔符、重复字段、工具调用标签或内部推理。
5. 若原文对白或正文中本身包含与协议标记完全相同的字面文本，不得擅改原文；需要由外部先转义或人工处理，不能假装该冲突已经解决。

# 严格输出格式

全部输出以 _::~OUTPUT_START::~_ 开始，以 _::~OUTPUT_END::~_ 结束；每条单行文案之间用独占一行的 _::~RECORD::~_ 分隔；起止标记仅包围整批输出。这些是批量解析的外层协议，不属于单条文案内容。

不要输出 JSON、代码块、表头或分镜编号。除协议规定的位置外，不在字段内容中使用上述标记。

格式示例仅说明结构，不可照搬示例剧情：

_::~OUTPUT_START::~_
阿青坐在书房桌前，抬头看向门口：“谁在外面？”
_::~RECORD::~_
小林站在书房门外，抬手敲门。
_::~OUTPUT_END::~_
