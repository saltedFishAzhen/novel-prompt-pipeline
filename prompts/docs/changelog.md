# 提示词变更与验证

提示词以 [src/](../src/) 为权威源，构建产物和内容寻址发布版不可手改。正式运行固定发布快照；当前版本由 [current.json](../current.json) 指定。

- 资产提示词按角色、场景、物品分别生成：角色保留肖像、多视图和细节条；场景按单视角生成后由管线组合四视图；物品生成 1:1 单图。原文事实与状态需要人工复核。
- 视频提示词按分镜类型使用 I2VA 或 Ref2VA，保留动作接触链和实际参考输入限制。结构正确不保证动作或空间一致性，见[视频验证](../../docs/verification/video-door-entry-verification.md)。
- 导演技能提炼涉及分镜、连续性及场景视角。七案例文本对照与盲审结果见[评测记录](director-round24.md)。
- 戏剧技能提炼涉及剧本、改写、摘要及资产绑定。八案例文本对照与盲审结果见[评测记录](drama-round25.md)。
- 全 16 节点统一评测后，修正了无据指定性别及两处元说明；最终版本经真实 LLM 首过 16/16、独立语义复审及报告门禁后发布，见[第 26 轮审查](unified-node-review.md)。

本目录的评测是提示词迭代，不是模型权重训练。真实 LLM、图像和视频验证应分别记录版本、输入、配置与结果；[已知问题](known-issues.md)列出仍需核实的边界。
