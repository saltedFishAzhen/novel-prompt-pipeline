# 词数预算

各资产提示词都保留 **450 词硬上限**。词数目标用于指导表达，不是让模型编造事实或重复画面说明的下限；原文稀疏时允许更短。以 [modes/](../../src/modes/) 中的 JSON 文件为目标区间的唯一权威来源。

| 模式 | 基准参考 | 变体参考 | 画面 |
|---|---:|---:|---|
| 角色 | 300–400 词 | 350–450 词 | 原有角色设定板、三视图与细节格 |
| 场景 | 100–200 词 | 120–240 词 | 单张全景、单视角 |
| 物品 | 30–180 词 | 30–220 词 | 单张单视角；断裂局部约 30–80 词 |

角色、场景及物品普通画面变体保留逐字一致的共享骨架、Reuses 子句和原文有据的状态；物品断裂局部分支只保留有据的局部事实及 Reuses，不复制整体骨架。超出硬上限时先删重复和无关修饰，不删除原文支持的识别锚点、重要状态、颜色绑定或相对尺度。物品变体在 Reuses 之后的状态段须为不少于 8 词的完整英文句子；基准物品不强制独立状态段。其他模式以各自源码要求为准，任何模式均不得为凑字数添加画面事实。
