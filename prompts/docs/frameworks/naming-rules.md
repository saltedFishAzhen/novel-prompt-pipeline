# 命名规则

三类资产统一的命名体系；与提示词源码冲突时以 [common.json](../../src/common.json) 和 [modes/](../../src/modes/) 为准。

---

## 1. 核心规则

### 有变体时：基准一律「默认的+X」

只要某实体存在**多个记录**（变体），基准记录的名字一律为 `默认的+原文名`。

```
默认的出租屋   ← 基准（原文有变体）
暴雨淹水的出租屋  ← 变体
```

**不得**直接用地名/人名/物品名本身做基准名。

### 无变体时：用原文名本身

```
院子    ← 原文只有这一种状态，直接用地名
菜刀    ← 单状态物件
老赵    ← 单造型角色
```

---

## 2. 优先级

「默认的+X」规则**优先于**「name 保留原文写法」的保真规则。

「默认的」三个字属于命名规则要求的构造，不算改写原文。模板中已明确写出这个优先级，避免模型在两条规则间二选一。

---

## 3. 变体命名

格式：**状态说明 + 原文名**，状态在前、实体在后。

- 不加括号、不加标点
- 状态说明**最多 8 个汉字**（不用「词」，因为中文分词无可计算口径）
- 只保留区分该状态所必需的词
- 读起来自然

### 正例

| ✅ | 说明 |
|---|---|
| `门破窗帘落的房间` | 3 个状态词，简洁 |
| `暴雨淹水的出租屋` | — |
| `断成两段的铜钥匙` | — |
| `穿着白衬衫的许青` | — |

### 反例

| ❌ | 问题 |
|---|---|
| `门下角破窗帘落的出租屋东屋` | 堆叠拗口，超 8 字 |
| `夜门闭的…` | 半文半白 |
| `铜钥匙（断成两段）` | 用了括号 |
| `周明（雨衣）（雨夜）` | 括号 + 多个状态并列 |

---

## 4. aliases

### 规则

**每条记录都填不带状态说明的原文名**，包括基准记录和单状态记录。

```
默认的铜钥匙      aliases: 铜钥匙
断成两段的铜钥匙   aliases: 铜钥匙
菜刀             aliases: 菜刀
```

### 为什么基准也要填

名称来源校验的三条路：exact / alias / 2+ 字子串。

`默认的出租屋` 可以通过原文名别名或连续子串命中。aliases 非空是单独的提示词契约，不能仅依赖启发式来源匹配。

### 基准与变体的 aliases 相同是有意设计

它们不承担区分职责，**区分只靠 name**。

### 其他别名

原文另有专名时照常追加，英文逗号分隔：

```
aliases: "铜钥匙, 那把钥匙"
```

### 禁止

- 场景、物品的别名混入人物名；角色的别名应使用原文角色名或称呼
- 用服装或状态说明代替实体原名
- 把泛指称谓（屋子、里头、那边）当别名
- 写成 `[]` 或 `null`（必须是字符串）

---

## 5. 不得编造地名

以原文**首次出现的具体名称**为准。

- 原文写「房间」「屋子」「屋里」→ 就用「房间」
- 原文从没写「出租屋」→ **不能**写成「出租屋」

避免照搬示例中的地名，以原文为准。

泛指称谓（屋子、里头、那边）不单独建条。

---

## 6. 各模板的系统差异

| | scene | character | prop |
|---|---|---|---|
| 基准前缀 | 默认的+地点 | 默认的+角色 | 默认的+物品名 |
| 变体上限 | 4 条 | 无（按造型） | 3 条状态 |
| Reuses 标签 | `Reuses base location:` | `Reuses base look:` | `Reuses base item:` |

---

## 7. 第一人称「我」的特殊处理

三条优先级，按顺序判断：

1. **原文给了具体姓名**（「我叫许青」）→ name 用姓名，不用「我」
2. **原文通篇只有「我」**，没有任何姓名或他人称呼 → name 填「我」，且**只输出一条记录不拆造型**（否则会出现「默认的我」「穿湿衬衫的我」这类非原文用语）
3. **原文有他人对「我」的称呼**（「老许」「阿青」）→ 用该称呼作 name，并写进 aliases

第 2 条意味着：无名的第一人称叙述者若换过多套衣服，只能压成一条记录。这是有意取舍。

---

## 8. 输出前自查

- [ ] 有变体的实体，基准名是否带「默认的」前缀
- [ ] 无变体的实体，name 是否就是原文名
- [ ] 全数组 name 是否唯一
- [ ] 每条 aliases 是否非空
- [ ] 状态说明是否 ≤8 个汉字、无括号
- [ ] 地名是否是原文实际出现的词
