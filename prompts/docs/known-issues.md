# 已知问题与验证边界

- 文本校验无法确认颜色、材质、数量、动作和方位均忠于原文，也不能完全拦截解释性元说明与无依据推断。未知的断裂物件部位尤其需要检查是否被模型补造。
- 同一实体变体的身份锚点比较是启发式警告，不能证明共享骨架逐字一致；状态段检查也不能判断其语义是否忠于原文。
- 角色多视图和细节条需检查面部、朝向、配饰与服装一致性。第一人称只有「我」且没有具体姓名或称呼时，当前规则不拆多个造型。
- 场景四视角流程曾完成实测，但反向视图出现近似镜像、俯视略带透视和已移走的物件重新出现；物品样例也出现断面过白或额外掉瓷。画面仍需逐项验收，见[验证记录](../../docs/verification/verification.md)。
- 参考图不能保证像素锁定。开门视频曾出现动作启动偏晚、提前松手和换手；详见[视频验证](../../docs/verification/video-door-entry-verification.md)。
- 人像照片参考已验证输入路径，尚未以用户照片实测人脸相似度。文本通过不等于成图、视频或音画同步通过。

继续扩充独立原文与重复调用，对照原文检查文本，并通过真实图像和视频验证空间、人物、动作和时间一致性。
