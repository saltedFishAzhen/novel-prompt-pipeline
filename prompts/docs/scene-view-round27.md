# 第 27 轮：场景新机位的文字与代码验证

本轮按用户要求不生图，不调用 ComfyUI，也不上传参考图。此前实际反打和斜俯视样本保留原机位，单独删除画风词中的 `framing` 未改变这一现象；因此本轮不把某个词认定为已证实的根因，也不把文字通过视为画面问题已经解决。

## 修改

- 反打先描述目标视野：从对侧看回原机位，已知入口与窗相对时交换背景和相机之后的区域；保持物体的世界位置，按新视点投影，避免复制旧屏幕坐标或做镜像。
- 斜俯视先写可见地面、家具顶面与侧面及透视深度；通过移动虚拟机位越过原先遮挡，而非删除门框等实物。仅在室内需要时使用展示性屋顶剖开。
- 新露出的普通表面允许沿用已知材质，不因此补造门窗、房间、家具或未知坐标。
- 默认画风增加环境专用前后词，保持原有人物画风文字。场景变换提交词以视角指令开头，外观词随后加入，并明确机位和可见面由当前编辑指令决定。
- 场景缓存和运行身份采用 `scene-four-views-v2`，固定实际环境画风文字；旧策略结果不作为新构图的缓存。尚无场景进展的旧任务可补齐身份后继续，保留原快照和其他任务；已有旧场景进展时阻止混用。

## 文本评测

基准为 `4b69280b41d64b25e9f4662477a094edc482c9d64f012a6568e0f7347b9e6f2e`，候选为 `aeaf94c652ad8d1ae284326457bee89793a0d928b22958cc21b01a9e1765a74e`。两组使用同一套 [8 个困难用例](../evaluations/suites/scene-view-regression.jsonl)，覆盖门窗对置、室外地标、空间关系未给出及光源位置。用例中的 criteria 用于事后审查，不渲染进模型请求。

评测通过统一入口调用管线配置的 `gpt-6.1-sol`，基准与候选各 8 次，均首次通过结构检查；候选输出为 99–114 词。完整输入、原始输出和请求记录保存在[基准](../evaluations/rounds/round27/baseline/)和[候选](../evaluations/rounds/round27/candidate/)目录。每配置每用例仅一个样本，不据此推断稳定成功率。

[匿名对照审阅](../evaluations/rounds/round27/blind-review.md)完成后才[解盲](../evaluations/rounds/round27/blind-map.json)：候选 5 项更好、1 项略好、2 项相当，未出现基准更好的项目，见[汇总](../evaluations/rounds/round27/comparison-summary.json)。较好主要体现为明确已知顶面、地面、新背景和近远关系。审阅者此前看过本轮默认 16 节点结果，因此该比较不是严格首次接触双盲，也不是实际图像效果测量。

另外对候选执行默认全 16 节点真实评测，16/16 首次通过结构检查，见[完整记录](../evaluations/rounds/round27/default/)。[独立语义审查](../evaluations/rounds/round27/default-review.md)未发现 P1/P2，保留两处 P3：俯视输出额外限定衣物在家具占地之间；未修改的开门分镜节点额外写门扇靠近内侧墙。这些是无据的空间具体化，不能把本轮称为语义零问题，也没有观察到它们造成实际画面变化。

## 离线提交词检查

对同一组 8 个用例，将基准节点输出挂载原通用画风，与候选节点输出挂载新场景画风比较。最终正向词从 463–468 词缩为 202–217 词，候选的机位指令始终位于开头。该比较同时改变了节点输出和挂载策略，不是单个变量的效果试验。

[检查记录](../evaluations/rounds/round27/composition-check.json)只离线准备 Qwen API 图并使用占位参考名，没有提交。除正向词外，实际工作流绑定、参考槽、负向词、尺寸和种子保持相同；这验证了参数传递范围，不能验证模型是否按新机位生成。

后续生图验收仍须核对：反打的新背景与可见面、物体近远与左右投影、俯视地面和顶面占比、遮挡物是否仍在世界原位，以及新视角是否保持物体数量和状态。

## 发布与代码验收

候选通过默认全节点报告门禁后已发布为当前版本 `aeaf94c652ad8d1ae284326457bee89793a0d928b22958cc21b01a9e1765a74e`，新运行自动读取它。程序回归为 230 项通过、5 项因 Windows 链接权限跳过、62 项子测试通过，包含三种参考绑定、最终提示词顺序、画风回退、旧场景缓存失效和续跑身份检查。

全仓回归还暴露了既有资产文件同哈希并发发布的 Windows 替换竞态；关联、导入及恢复文件现共用内容哈希锁，文件完整性和选择事件均保留。这个存储修复不是场景画面改善的证据。
