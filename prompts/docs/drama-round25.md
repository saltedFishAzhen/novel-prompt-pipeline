# drama-skills 方法蒸馏：第 25 轮

本轮参考 [drama-skills 固定版本](https://github.com/zenstory-ai/drama-skills/tree/8cf7404981b7095b498e061832bb3c9ffd6a42be) 的一般创作方法，以原创措辞改进小说转剧本、单条与批量改写、上下文摘要、资产绑定和连续性六个节点。上游项目使用 MIT 许可证，版权和完整许可见工作区 `THIRD_PARTY_NOTICES.md`。

本项目保留原有节点协议和实际工作流：按文本证据区分观众与人物所知、意图与已发生事实、回忆与当前动作；跟随原文安排信息披露；声音来自画外时不自动把说话者放入画面，未打开容器中的物品不自动进入首帧。没有套用上游整套创作工作流、画风、镜头模板或模型能力表。

## 固定用例与结构结果

[用例文件](../evaluations/rounds/round25/cases.jsonl)含 8 个案例：两条小说转剧本、批量改写、单条改写、上下文摘要、两条资产绑定和连续性摘要。`expected` 只用于评估，未发送给模型。基准 `a79352b63853197163a9e54eda2232f16385020db3c93f84c3f9640f72135fef` 与候选 `ba85ad15e074c2e62c60cba8544c271ba260d3deaf297bdc7d8ef63960d36ac5` 各对每个案例使用 `gpt-6.1-sol` 的 `chat_completions` 调用一次，共 16 次；原始响应和逐项结构结果保存在 `round25/baseline/` 与 `round25/candidate/`。

两组分别为 **8/8** 结构通过。隐藏物和画外声音两个资产绑定案例中，两组的全部资产 ID 和首帧资产 ID 均与预期精确一致；这两项是双方均成功，不能记作候选提升。结构通过本身不证明剧情语义或事实保真，须结合匿名审查。

## 匿名语义审查

独立审查先只看随机化的 [X/Y 输入与结果](../evaluations/rounds/round25/blind-input.json)，完成[逐案报告](../evaluations/rounds/round25/blind-review.md)后才解盲。八组均判相当，未发现明确内容或协议错误：心声和回忆未改成当前对白，揭示顺序与人物知情边界保留，批量编号顺序为 9、2、17；两个绑定结果逐项一致，连续性摘要未把开盒计划写成已完成。

解盲后有两处轻微措辞观察：基准摘要用“催”概括对白，语气较原文稍强；候选连续性摘要在已说明声音来自画外后，仍说发声者是否入画无法确认，可以表达得更明确。审查没有把它们判作事实失败或整组优劣。本轮未观察到候选文本相对基准的明确提升，也未观察到需阻止发布的重大回归。

隔离目录中的提示词 build 成功，26 项一致性检查及 3 个资产 fixture 自测通过。`ba85ad15e074c2e62c60cba8544c271ba260d3deaf297bdc7d8ef63960d36ac5` 完成了本轮八案例盲审和统一 16 节点真实评测；后续人工检查发现一项角色性别无据推断，以及小说转剧本和上下文摘要的轻微元说明问题。针对这些问题修订后的候选 `4b69280b41d64b25e9f4662477a094edc482c9d64f012a6568e0f7347b9e6f2e` 已通过统一报告门禁激活。独立角色测试使用配置的 LLM 真实调用一次，结构、性别依据和人工事实核对通过；原始响应、注入请求及审查见[第 26 轮证据](../evaluations/rounds/round26/character-independent/)。这只是一个角色样本。新候选的 16 节点真实调用首次结构检查为 16/16 通过，证据见[第 26 轮全节点记录](../evaluations/rounds/round26/final/)；独立语义复审已完成，本次 16 个样本中原性别补造和两处元说明均已修正，未见新的实质回归，详见[全节点语义审查](unified-node-review.md)。本轮旧候选的审查结论不能冒充修订后候选的结果。
